# Sai Jyothi Dealers — Website Redesign

## Run locally
1. Extract this folder.
2. Open `index.html` in a browser, or open the folder in VS Code and use the Live Server extension.
3. No npm install or build step is required.

## Files
- `index.html` — all page sections and original site content
- `styles.css` — responsive premium design
- `script.js` — mobile menu, FAQ accordion, reveal animations, inquiry validation and WhatsApp handoff

## Important inquiry form note
The inquiry form currently opens WhatsApp with the entered details pre-filled. A selected photo/PDF is validated (max 10 MB), but browsers cannot attach that file automatically to a WhatsApp link; the visitor must attach it manually in the WhatsApp chat. For server-side submissions and file uploads, connect a backend or form service before launch.
